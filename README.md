# 🤖 VK DeepSeek Bot — умный помощник для сообщества ВКонтакте

Этот бот для ВКонтакте создан, чтобы помогать клиентам группы **«КОМПЬЮТЕРНЫЕ РЕШЕНИЯ - Сборка ПК на заказ»**. Он консультирует по игровым, офисным и домашним ПК, публикует свежие новости из мира технологий и записывает все диалоги для менеджеров.

Бот работает через **OpenRouter** (бесплатные модели, включая DeepSeek, Llama, Gemma), что обеспечивает быстрые и осмысленные ответы без затрат на API.

---

## ✨ Возможности бота

✅ **Консультации по компьютерам**
- Различает игровые, офисные, мультимедийные ПК и мини-ПК.
- Даёт актуальные цены на февраль 2026 года (с учётом кризиса памяти).
- Объясняет, почему выросли цены на ОЗУ и SSD.

✅ **Умный диалог с контекстом**
- Помнит историю беседы с каждым пользователем.
- Следит за логикой разговора и не задаёт одни и те же вопросы дважды.

✅ **Готовая клавиатура с кнопками**
- Пользователи могут выбрать категорию одним нажатием.
- Кнопки: «Игровые ПК», «Офисные ПК», «Домашние/Мультимедиа», «Мини-ПК», «Связаться с менеджером», «ℹ️ О группе».

✅ **Автоматические новости на стене**
- Каждый день в 12:00 публикует 2 свежие новости из RSS 3DNews.
- Если есть изображение — оно подгружается прямо в пост (ВК сам показывает превью).
- Красивое оформление с эмодзи и хештегами.

✅ **Защита от спама**
- Не даёт одному пользователю писать чаще 1 раза в 3 секунды.

✅ **Логирование всех диалогов**
- Все сообщения сохраняются в CSV-файл (`conversations_log.csv`) с датой, user_id, ролью и текстом.
- Можно анализировать, какие вопросы задают чаще всего.

✅ **Приветственное предупреждение**
- При первом обращении бот сообщает, что он автоматический помощник и не даёт точных цен, а только фиксирует пожелания.

## 🛠 Технологии

- **Python 3.11+**
- **VK API** (vk-api, longpoll, клавиатуры)
- **OpenRouter API** (доступ к бесплатным AI-моделям)
- **Feedparser** (для RSS-новостей)
- **Schedule** (планировщик публикаций)
- **Python-dotenv** (безопасное хранение ключей)
